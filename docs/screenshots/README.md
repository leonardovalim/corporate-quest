# Screenshots for README

These screenshots are used in the project README.

## How to generate

1. Start the dev server: `bun run dev`
2. Install puppeteer: `npm i -D puppeteer`  
3. Run the capture script: `node docs/capture-screenshots.mjs`

Or take manual screenshots at 1280×800 from http://localhost:8080

## Expected files

- `01-home.png` — Home/title screen
- `02-classes.png` — Class selection (onboarding step 2)
- `03-origin.png` — Origin/background selection (step 3)
- `04-alignment.png` — Alignment grid (step 4)
- `05-attributes.png` — Attribute distribution (step 5)
- `06-skills.png` — Feat/skill selection (step 6)
- `07-summary.png` — Character summary (step 7)
- `08-gameplay.png` — Gameplay screen with narrative + sidebar
