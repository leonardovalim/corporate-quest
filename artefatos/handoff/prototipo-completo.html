Próximos passos naturais: extrair para tokens CSS (plugáveis no index.css), definir set de ícones (Phosphor Light 1.5px parece alinhar), mockar estados extras (burnout, critical success com animação, input focus), e rodar alguns playthroughs mentais para achar densidades que quebram.

Se quiser iterar: me diga se o tom arcade está na medida (podemos subir ou descer a CRT vignette, adicionar mais ASCII art, ou enxugar), e se quer que eu exporte os tokens para aplicar direto no projeto.
